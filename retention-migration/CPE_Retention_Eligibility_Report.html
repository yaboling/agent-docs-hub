Why P75 of stabilization, not the sensitivity analysis minimum? The sensitivity analysis shows 91% accuracy at ≥200 installs, but this is misleading: that pool is dominated by days from games already at 5K–180K installs, which skews the accuracy upward. The P75 stabilization threshold is derived per-game — it directly measures "at what volume does each individual game enter a persistent stable regime," validated with a streak + persistence check. P75 means 75% of games have definitively passed that point.

Why a dual threshold? A game with a 5% D7 retention rate needs 10× more installs than a game with 50% retention to accumulate the same training signal. Retained D7 count directly measures the quality of feedback the model has received, making it a more robust signal for low-retention games.

Operational implication: Games not yet meeting either threshold should remain in learning phase. Avoid bid/budget changes during this window — changes confound the model's feedback loop and can delay convergence.

Why does mean bias drift upward over time while % within ±20% stays stable? The median bias stays flat near 0 throughout — the upward mean is driven by a small number of high-spend games (Game 500237245, 500241521) with persistent positive over-prediction. This is a model calibration issue for high-volume campaigns, not a universal learning phase problem. See the Outlier Analysis section below.

Per-Game Stabilization Analysis
For each game, stabilization is defined as: a 3-consecutive-day streak within ±20% bias, followed by ≥70% of remaining observed days also staying within ±20% (minimum 7 post-entry days required). This ensures early lucky streaks do not false-trigger the "stable" classification.

Stabilization happens very fast in days (median 2 days) but requires ~655 installs. This means the limiting factor is volume, not time — a high-traffic game can exit the learning phase in days, while a low-traffic game may take weeks to accumulate 200 installs. The eligibility rule should be volume-based (installs or retained D7), not purely time-based.
