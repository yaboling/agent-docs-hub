3. Event Arrays — sdk_event_name_first_seen_arr
Array Structure & Fallback Mechanism

Each array is a list of (sdk_event_name, first_seen_at) structs recording the first time each event fired for the install. Two arrays exist:

ArrayCoverageMax size
sdk_event_name_first_seen_arr All custom events 266 (unattr), 185 (attr)
sdk_event_name_first_seen_arr_lc LC events only 68 (unattr), 67 (attr)

-- BQ unnest pattern (double unnest required):
UNNEST(arr.list) AS arr_elem,
UNNEST([arr_elem.element]) AS e
→ e.sdk_event_name, e.first_seen_at

Two-Tier Event Naming & Fallback (Adjust MMP)
Each event has two tiers: event_type (broad category) and sdk_event_name (registered name). When sdk_event_name is absent (Adjust), the pipeline falls back differently for each array:
Custom array fallback (Adjust):
Uses event_type if it is in the canonical list:
registration, tutorial_complete, level_complete, subscribe, spent_credits, start_trial, achievement_unlocked, share, invite, custom
Otherwise falls back to "custom" (dropped — zero count in dataset).
LC array fallback (Adjust):
Cannot reuse event_type — level_complete IS the filter criterion. Falls back to "_no_sdk_event_name" instead.
! _no_sdk_event_name = 6.88M unattr + 521K attr in LC array. Zero in custom array.

6. Modeling Recommendations
PriorityRecommendation
High Use isAttributed as a primary conditioning feature or train separate attributed/unattributed model branches. Event taxonomies, LC rates, and MMP partners differ fundamentally between the two populations.
High Use cum_has_lc_event_d7 as the primary training label for event-tracking games. cum_has_event_dx (NULL=0) is a valid 17% positive-rate label overall, but has no discriminative power within event-configured installs (conditional positive at D28 = 99.997% — near-zero negatives in that population).
High For IOJ/deposit optimization, use regression targets (deposit_count_d7, cum_deposit_sum_d28) rather than the binary cum_depositor_d28 flag (near-zero negatives).
Medium Impute NULL labels as 0 — do not filter them out. NULL installs are valid true negatives from advertisers without MMP event tracking. Excluding them silently removes 83% of the dataset.
Medium Add has_unnamed_lc_event boolean feature for the _no_sdk_event_name population (22% of attributed LC-positive, 11% of unattributed). These are Adjust installs with valid LC behavior but no named SDK event.
Medium Normalize event name case — at minimum lowercase all sdk_event_name values. Four registration variants (Register, register, registration, af_complete_registration) represent the same funnel step.
Medium Engineer first_seen_at as log(1 + hours_after_install). H0 is ~16× H1 — using raw timestamps encodes timezone and calendar noise rather than behavioral signal.
Low Use ARRAY_LENGTH as a feature. Non-zero directly identifies event-configured installs. Log-transform recommended (max = 266, highly skewed).
Low Investigate the level_end_success_* series (ranks 7–13 for attributed LC, ~40–47K users each). Likely from a single large publisher — confirm whether over-representation warrants publisher-level sampling.
