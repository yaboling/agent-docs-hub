Bias by Game Genre (SensorTower)

Genre from unified_app_all_fields.sensortower_game_genre, joined on store bundle ID + platform. 85% of spend is Puzzle (Match-3).

Puzzle / Match Pair is the entire over-prediction story: 85% of total LC spend ($27.6M) is in Puzzle games — almost entirely Match-3 (Match Pair subgenre). These games set rare, late-funnel level milestones as targets (actual LCR 0.16–0.40%), while the model predicts a generic ~25% LC rate. This structural mismatch produces +13,000–15,000% model bias for the Puzzle genre. Strategy games show the opposite: 44 observed LC events per converting install → model severely under-predicts (−99.5%).

Genre — Model Bias

Game × Event Deep Dive

Within the same game, harder-to-achieve target events carry far higher model bias.

Key insight: Within the same game, the harder the target event is to achieve (lower actual LC rate), the more the model over-predicts. Events that fire on >15% of users are near-calibrated or under-predicted. Events that fire on <3% carry 300–1,800% positive bias — the model extrapolates from general LC behavior rather than learning the specific event's rarity.

Deep-Dive: Heavily Over-Valued (game × event) Pairs

Pairs with >$5K spend and >100% model bias — ~$993K total spend across 27 pairs. Three root cause categories.

① MMP / Attribution / Retargeting events (~$375K): Events like golden_android_conversion_mid (MMP event, actual LCR 0.07%, bias +667%) and segment_lambdas_first_offer_reconciled (retargeting signal, bias +213–728%) are not gameplay events. Developers tagged them under LC conversion type; the model has no signal for these.

② Revenue / monetization proxy events (~$166K): revlow, superlow, netrevenuereachedmin7, reach_viplv2 — revenue thresholds or VIP tiers, not gameplay. LCR 1–5%, bias 170–555%.

③ Rare genuine gameplay events (~$452K): Real milestones like eventw (LCR 2.0%, bias +480%) and log_city_upgrade_6 (LCR 3.3%, bias +326%). Avg_pred is 5–8× above actual LCR universally — the model predicts a floor of 5–25% regardless of true event rarity.
